# Game_patterns

This repository contains the source for the paper
`A Permutation Avoidance Game with Reverse Replies and Monotone Traps`
together with the public reproducibility code used in the main manuscript.

## Contents

- `ItsAllFunAndGamesUntilMonotonicity.tex`
  Main manuscript source.
- `references.bib`
  Bibliography for the manuscript.
- `code-permuta/`
  Python scripts using `permuta` for the exact computations cited in the paper.

The exploratory appendix material is intentionally not part of this public
repository.

## Reproducibility

Install `permuta` in a Python 3.11 environment and run the scripts from the
repository root. The manuscript's reproducibility section and
`code-permuta/README.md` give the exact commands used for the results cited in
the paper.
